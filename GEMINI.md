# Sarah IA — Instructions & Règles Globales

## 📱 Règle d'Or : Interface 100% Identique et Universelle (iPhone 5S à iPhone 17+)
- Toute amélioration ou modification de l'interface graphique (UI/UX) s'applique obligatoirement à **toutes les versions et tous les modèles** d'iPhone sans exception (de l'iPhone 5s sous iOS 12.0+ jusqu'à l'iPhone 17+ sous iOS 18.0+).
- L'expérience, le design sombre/néon, la disposition, les composants (Composer, Sidebar, Orbes des 4 agents, cartes multimédia) et les fonctionnalités sont **strictement identiques** sur tous les téléphones.
- Les modifications doivent être synchronisées entre le code SwiftUI (`ContentView.swift`), le code UIKit natif (`LegacyChatViewController.swift`) et le simulateur interactif (`index.html`).
