# 💻 Sarah IA — Version PC & Compagnon Ordinateur

Compagnon PC officiel pour **Sarah IA** permettant :
1. **Liaison Sans Fil Instantanée** : Scannez le QR Code affiché sur l'écran de votre PC avec votre iPhone (ou saisissez le code PIN à 6 chiffres).
2. **Génération Vidéo IA Déportée (Haute Puissance)** : Rendu de vidéos IA au ratio **16:9 PC (1920×1080)**, 9:16 vertical et 1:1 carré avec offloading sur la carte graphique de votre ordinateur.
3. **Architecture Hybride Optimisée** :
   - 📸 **Photos** : Générées à 100% en local sur l'iPhone via le Neural Engine A15 / CoreML.
   - 🎬 **Vidéos** : Générées en haute fidélité sur le PC compagnon et synchronisées avec le téléphone.

---

## 🚀 Démarrage Rapide

### 1. Lancement du Serveur sur PC
Double-cliquez sur `start.bat` ou exécutez dans le terminal :
```bash
node server.js
```

### 2. Ouverture sur le PC
Ouvrez votre navigateur web sur :
[http://localhost:8080](http://localhost:8080)

### 3. Connexion depuis l'iPhone
1. Ouvrez l'application **Sarah IA** sur votre iPhone.
2. Allez dans **Réglages** (⚙️) ➔ **Version PC & Compagnon Ordinateur**.
3. Appuyez sur **Scanner le QR Code sur le PC** et visez l'écran de votre ordinateur.
4. Votre iPhone et votre PC sont instantanément reliés !
