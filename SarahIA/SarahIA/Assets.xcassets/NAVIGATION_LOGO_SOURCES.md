# Logos de navigation dans Sarah IA

Ces fichiers sont des assets SVG **embarqués** dans l'application iOS. L'affichage ne nécessite aucun téléchargement externe. Ils servent uniquement à identifier les applications de navigation proposées aux utilisateurs.

| Asset | Source utilisée |
|---|---|
| SarahAppleMapsLogo.imageset/logo.svg | https://github.com/homarr-labs/dashboard-icons/blob/main/svg/apple-maps.svg |
| SarahGoogleMapsLogo.imageset/logo.svg | https://github.com/homarr-labs/dashboard-icons/blob/main/svg/google-maps.svg |
| SarahWazeLogo.imageset/logo.svg | https://github.com/homarr-labs/dashboard-icons/blob/main/svg/waze.svg |

Collection : https://github.com/homarr-labs/dashboard-icons (licence du dépôt : Apache-2.0 pour la collection). Les marques et identités visuelles restent la propriété de leurs titulaires et leur emploi ici ne signifie ni affiliation ni approbation.

Les boutons Plans / Google Maps / Waze transmettent les **coordonnées réelles** de la recherche MapKit à chacune des applications via leur système officiel d'ouverture externe.

Références techniques :
- https://developer.apple.com/documentation/mapkit/mkmapitem/openmaps(with:launchoptions:)
- https://developers.google.com/maps/documentation/urls/ios-urlscheme
- https://developers.google.com/waze/deeplinks/
