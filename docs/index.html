LE GUIDE

De ce site
à votre iPhone.

Le fichier IPA est distribué en dehors de l’App Store. Prévoyez un outil de signature avant de commencer.

  1. 1

    Récupérez le fichier

    Appuyez sur « Télécharger le fichier IPA ». Retrouvez ensuite SarahIA.ipa dans vos téléchargements.

  2. 2

    Importez l’application

    Ajoutez le fichier à votre outil de signature compatible avec iOS.

  3. 3

    Terminez l’installation

    Suivez les instructions de cet outil pour signer et installer Sarah IA, puis ouvrez l’application.

i

Vous n’avez pas encore d’outil de signature ?
Le fichier IPA ne s’ouvre pas comme une application déjà installée. La méthode et les conditions d’installation dépendent de l’outil utilisé.

Signaler un problème ↗
Qu’est-ce que je télécharge ?+

Le fichier d’installation de Sarah IA pour iOS, au format IPA. Il doit être signé avec un outil adapté avant de pouvoir être installé sur l’iPhone.

Pourquoi le fichier ne s’ouvre pas ?+

Une IPA téléchargée n’est pas encore une application installée. Importez-la dans votre outil de signature, puis suivez les étapes qu’il indique.

Est-ce une version définitive ?+

Non. Il s’agit d’une version de test. Certaines fonctionnalités peuvent encore changer ou rencontrer des problèmes.

Comment décrire un bug ?+

Indiquez votre modèle d’iPhone, votre version d’iOS, la version de Sarah IA et les étapes qui provoquent le problème. Une capture d’écran peut aider. Masquez vos informations personnelles avant de la partager.
